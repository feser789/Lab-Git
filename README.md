# Lab-Git

Програма на C++, яка обчислює значення функції `y = f(x)` для заданого діапазону значень `x` з певним кроком `h`.

**Можливості програми:**
- Введення початкових даних через консоль або файл `input.txt`.
- Перевірка коректності введених даних.
- Обчислення значень функції для кожного `x` у заданому діапазоні.
- Виведення результатів у консоль.
- Можливість збереження результатів у файл `file.txt`.
- Наявність автоматизованих тестів із використанням Google Test.
